Política de privacidad de Hermes personal

Última actualización: 19 de octubre de 2026.

Hermes personal es una aplicación de uso exclusivamente personal. Su único usuario es su propietario.

Datos a los que accede

Con el consentimiento expreso del propietario, accede a su cuenta de Google (Gmail, Google Calendar, Google Drive, Contactos, Hojas de cálculo y Documentos) solo para responder a sus propias peticiones y para guardar sus copias de seguridad.

Uso y almacenamiento

Los datos no se venden, no se ceden a terceros y no se usan para publicidad. Los permisos de acceso se guardan en el servidor privado del propietario. El texto necesario para responder a cada petición se procesa con el proveedor del modelo de lenguaje que usa el asistente.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions.
